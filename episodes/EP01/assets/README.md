# EP01 Character Assets

The graduate-duck host is based on the character prototype supplied by the
project owner on 2026-07-21. The production sprite sheet was regenerated from
that reference to remove labels and panel borders and to provide consistent
animation poses.

- `duck_sprite_sheet_chroma.png`: production source sheet on a chroma background
- `duck_poses/*.png`: transparent compositing assets used by Manim
- approved use: Silent Sparks accessible VEX IQ educational content
- animation method: pose changes without lip synchronization

The source character should not be replaced or materially redesigned without
project-owner approval.
