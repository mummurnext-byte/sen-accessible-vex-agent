# Source Policy and Core References

## Source Priority

1. VEX IQ (2nd generation) Blocks API
2. VEX Library
3. VEX Education STEM Labs and Activities
4. Physical testing with the project's own VEX IQ hardware
5. Community sources only when clearly labeled and independently verified

Do not use a community claim as the sole source for a hardware limit, safety threshold, block behavior, or classroom instruction.
