# 48-Episode Curriculum Roadmap

## Program Structure

- 24 weeks, two episodes per week.
- VEX IQ (2nd generation), VEXcode IQ Blocks only.
- Learners are deaf and hard-of-hearing beginners aged 8-14.
- Every eighth episode is an integration challenge.
- Each episode has one visible behavior and one measurable success criterion.

| Week | Episode | Public title | Blocks and concept | Visible success state |
| --- | ---: | --- | --- | --- |

| 1 | EP02 | Build a Visual Port Map | Device configuration; ports; motor direction | Learner matches every cable to a labeled port card |
| 2 | EP03 | Your First Block Sequence | `when started`; ordered drivetrain commands | Robot follows three numbered actions in order |

## Scope Boundaries

- AI Vision is excluded from the core 48 episodes because it is not required for a beginner path and may not be available in every classroom.
- Sound may be included as an optional enhancement, never as the only signal.
- Competition strategy is an extension after the foundational curriculum, not the primary objective of this first program.
- Each episode must remain teachable without relying on the public video's audio.
